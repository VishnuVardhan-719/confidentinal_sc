# Agent handoffs

Store one Markdown file per delegated task or cross-session handover here. Recommended name: `TASK-ID_agent_or_recipient_YYYY-MM-DD.md`.

Every handoff must include task ID, owner/agent, branch and base commit, files changed, implementation state, API/database contract changes, tests actually run and results, security/privacy notes, blockers, and next action. Do not put credentials, patient data or private account information here.
