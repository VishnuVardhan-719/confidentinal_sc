# SureCure Visit — Brand and Interface System (Proposed)

**Brand:** SureCure Visit. **Domain:** surecurevisit.in. Complete redesign desired. No invented legal company association, ratings, stories or medical badges. This file is guidance, not an approved logo.

## Design direction

Warm premium healthcare editorial feel: trust and usability, not generic AI SaaS. Example initial palette pending client sign-off: deep forest/teal `#0F5F59`, bright focus teal `#0A857C`, ink `#17282B`, warm paper `#FAF8F2`, mist `#E9F3F0`, warning `#B36D20`. Type: distinctive but highly legible Latin + complementary Telugu and Devanagari font families with proper fallbacks. Use scale/spacing tokens, restrained border radius, purposeful imagery and meaningful responsive layouts.

## Visual rules

No purple neon gradients, fake traction metrics, fake customer reviews, repeated cloned cards, untested stock/AI-generated images representing real doctors, particle effects everywhere, excessive glassmorphism or slow scroll hijacking. Public landing can use one accessible, lazy-loaded Three.js scene with still-image fallback. Anime.js only for purposeful highlights/reveals. CSS for simple transitions. Component patterns from 21st.dev must be adapted and licensed appropriately, not pasted wholesale without review. Shadcn/ui primitives must be customized and accessible.

## Pages

Landing hero, location search, four category pathways, how-it-works, real team/method, real approved stories, published memberships, provider registration, FAQ/footer. Role dashboards with tailored information architecture rather than one theme pasted across all. Doctor consultation should prioritize readable steps and predictable editing: Vitals, Assessment, Medications/Tests, Follow-up, Review/Sign. Unobtrusive status timeline and prominent Save Draft/error indicator. Emergency pages have no decorative motion.

## Localization and accessibility

Full English/Telugu/Hindi UI, correct text shaping, linguistic review for medical/financial statements, responsive small-device layouts, keyboard focus, contrast, WCAG-oriented controls, reduced motion, performance budget and no public sensitive information. Preserve original clinician-authored medical document language; never automatically rewrite dosage text.

Detailed policies: `docs/specs/DESIGN_ANIMATION_I18N.md`.
